# Deutsch Daily Deck community

Questions, support and product discussions for [Deutsch Daily Deck](https://github.com/saintheraldfaust/Deutsch), a German vocabulary trainer focused on recall, spaced practice and optional learning with others.

- [Ask a question](https://github.com/Dustymaterial/Deutsch-community/discussions/categories/q-a) about using the app or understanding its behaviour.
- [Discuss an idea](https://github.com/Dustymaterial/Deutsch-community/discussions/categories/ideas) for learning, accessibility or community features.
- [Report a bug](https://github.com/saintheraldfaust/Deutsch/issues/new) or contribute code in the main repository.

For a support question, describe what you expected, what happened and the steps to reproduce it. Include your browser and app version when relevant. Keep passwords, account codes, session cookies, email addresses and private chats out of public posts.

Q&A replies can be marked as an answer when they resolve the question. Keep feedback specific and respectful. Product ideas belong in Ideas; confirmed work is tracked through issues and pull requests in Deutsch.

This repository hosts discussion and documentation. The application code, learning guidance and vocabulary attribution remain in the [main project](https://github.com/saintheraldfaust/Deutsch). Repository documentation is [MIT licensed](./LICENSE).
